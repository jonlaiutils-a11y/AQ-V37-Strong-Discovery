# AQ V37.5 Beta3 P0.4 — Next-Day Pool

本版在 P0.3 基础上新增“盘中交易机会 / 收盘后下一交易日重点池”分离：

- 盘中：AQ + MQ + HR + RR + IM + 阶段 → Top强势交易机会。
- 收盘后/非交易时段：生成“下一交易日重点池”，使用全天强度、次日接力、3日延续、收盘位置、HR与资金状态综合排序。
- 次日重点池不是买入命令。下一交易日开盘后必须重新计算 MQ / HR / IM，再决定可进、等回踩或放弃。
- 高位高潮、过高涨幅、硬风险过滤、弱市场会降低收盘预选分。
- 保留 Cloudflare subrequest 修复：大页优先、最多3页兜底。

注意：交易日节假日不在前端硬编码，页面统一表述为“下一交易日”。
